## 本批新增的重要边界

- Query Route（查询路由）同时是 Authorization Resource Boundary（授权资源边界）：语义选对知识源并不代表访问令牌（Access Token）的受众和权限正确；
- MCP Intermediary（MCP 中间层）不得向上游服务透传入站访问令牌（Inbound Access Token），而应使用单独获取且受众匹配的凭据；
- 路由回退必须区分 Empty Result（空结果）、Service Unavailable（服务不可用）、Timeout（超时）、Authorization Failure（授权失败）和 Policy Denial（策略拒绝）；授权失败应 Fail Closed（失败关闭）；
- Hybrid Retrieval（混合检索）中的向量候选 `k`、文本候选窗口 `maxTextRecallSize` 与最终 `top` 是不同预算；前序截断不能由后续 Result Fusion（结果融合）或 Reranking（重排序）恢复；
- `filterOverride` 可覆盖目标向量查询的全局过滤器，遗漏 Security Trimming（安全裁剪）会形成实际越权风险；
- Query Sanitization（查询清洗）不能使检索文档变成可信输入，Indirect Prompt Injection（间接提示注入）、投毒文档、权限撤销和缓存泄露需要检索时防线；
- Candidate Window（候选窗口）是融合语义的一部分；Weighted RRF（加权倒数排名融合）的权重是策略系数，不是通道可信概率；
- Simple Fusion（简单融合）、Relative Score Fusion（相对分数融合）、Distance-based Score Fusion（距离分数融合）和 RRF（倒数排名融合）对重复节点和证据贡献的处理不同，框架升级必须固定 Source Commit（源码提交）并回归；
- 外部 Rerank API（重排序接口）会接收查询与文档文本，属于新的 Data-processing Boundary（数据处理边界）；自动截断、候选不足和过载故障不能都归因给模型质量；
- SaaS（软件即服务）、Private Deployment（私有部署）、Zero Data Retention（零数据保留）、企业合同与 Trial Key（试用密钥）的数据承诺不同，必须按实际部署审核。
