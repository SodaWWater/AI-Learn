# RAG 完备性验收标准

## Gate 1：来源冻结

- [x] 每个来源记录固定 Commit
- [x] 每个来源记录许可状态和公开发布策略
- [x] RAG 纳管文件形成明确清单

## Gate 2：来源单元盘点

- [x] 题目、语义标题、代码文件和资源文件全部生成来源单元
- [x] 占位文档、纯目录、项目清单与知识正文明确区分
- [x] 每个来源单元拥有稳定 ID、路径和定位信息
- [x] 未映射单元数量为 0

## Gate 3：知识原子化与去重

- [ ] 每个知识原子只表达一个可判断的结论、方法、约束或实现点
- [ ] 只有适用条件和语义均等价的内容标记为 `duplicate`
- [ ] `extends`、`contains`、`implements`、`compares` 不得删除
- [ ] 冲突内容进入冲突表并完成核验或明确标记待核验
- [ ] 变化内容记录版本和审核日期

## Gate 4：标准知识库

- [ ] 每个标准知识点至少关联一个来源单元
- [ ] 每个来源单元都映射到标准知识、参考资源、占位或结构单元之一
- [ ] 每个一级模块完成概要、原理、工程实现、权衡、对比、关系、错误和评估检查
- [ ] 使用一手资料与经典论文完成缺口检查
- [ ] 变化较快的内容按时效等级完成当前版本复核

## Gate 5：学习与面试产物

- [ ] 总导图覆盖全部一级知识模块
- [ ] 子导图覆盖标准知识点且不另造结论
- [ ] 学习正文、知识概要、概念对比和关系图均引用知识点 ID
- [ ] 原始题目能够反向定位到标准知识点
- [ ] 场景题均有公开原始出处和来源类型，不包含自拟公司题目
- [ ] 完成来源到知识、知识到来源的双向抽查

只有 Gate 1～4 全部通过，RAG 学习与面试产物才能标记为正式版。
