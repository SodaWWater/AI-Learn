# RAG 完备性验收标准

## Gate 1：来源冻结

- [x] 每个来源记录固定 Commit
- [x] 每个来源记录许可状态和公开发布策略
- [x] RAG 纳管文件形成明确清单

## Gate 2：来源单元盘点

- [x] 题目、语义标题、代码文件和资源文件全部生成来源单元
- [x] 占位文档、纯目录、项目清单与知识正文明确区分
- [x] 每个来源单元拥有稳定 ID、路径和定位信息
- [x] 未映射单元数量为 0

## Gate 3：知识原子化与去重

- [x] 每个知识原子只表达一个可判断的结论、方法、约束或实现点
- [x] 只有适用条件和语义均等价的内容标记为 `duplicate`
- [x] `extends`、`contains`、`implements`、`compares` 不得删除
- [x] 冲突内容进入冲突表并完成核验或明确标记待核验
- [x] 变化内容记录版本和审核日期

## Gate 4：标准知识库

- [x] 每个正式知识点至少关联一个来源单元（189 个正式原子均有来源；`RAG-07-001`、`RAG-13-011` 作为无来源 `inventory_draft` 库存占位排除）
- [x] 每个来源单元都映射到标准知识、参考资源、占位或结构单元之一
- [x] 每个一级模块完成概要、原理、工程实现、权衡、对比、关系、错误和评估检查
- [x] 使用一手资料与经典论文完成登记范围内的缺口检查（未覆盖范围和证据边界已登记，不宣称互联网永久完整）
- [x] 变化较快的内容按时效等级完成当前版本复核（动态产品/API 行为保留周期复核责任和日期）

## Gate 5：学习与面试产物

- [x] 总导图覆盖全部一级知识模块
- [x] 子导图覆盖标准知识点且不另造结论
- [x] 学习正文、知识概要、概念对比和关系图均引用知识点 ID
- [x] 原始题目能够反向定位到标准知识点
- [x] 场景题均有公开原始出处和来源类型，不包含自拟公司题目
- [x] 完成来源到知识、知识到来源的双向抽查

Gate 1～4 已在当前登记范围内通过。正式发布集合为 189 个有来源知识原子；2 个无来源原子仅保留为 `inventory_draft` 库存占位，不构成正式结论。动态产品/API 行为仍按版本和审核日期周期复核；本结论不宣称互联网永久完整。
