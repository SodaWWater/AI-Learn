## 一、这套资料要学什么

Claude Code 是面向终端和代码库的编程智能体（Coding Agent）。当前专栏总览把学习内容分成五条线：基础使用、工程化实践、源码机制、提示词工程和行业观察。适合采用“先会用，再理解工程边界，最后读主循环和上下文机制”的顺序。

## 三、初始学习路径

1. **先建立操作闭环**：命令行启动、项目范围、文件读取、修改、测试和回滚。
2. **再建立工程约束**：理解 `CLAUDE.md`、Skill、Subagent、MCP、Hooks 和 Plugin 的职责边界。
3. **先读源码原文建立直觉**：重点读 Query 主循环、Compact、检索、Memory、SubAgent、Skill。
4. **再进入 `讲解/` 做源码校准学习**：先完成 Agent Runtime，再进入 Context；Context 重点不是消息变量本身，而是信息注入与多层治理/压缩方案。
5. **最后做横向比较**：将 Claude Code 的 Agent、工具、记忆和代码库检索，与 AI-Learn 已有的 Agent、RAG、MCP 知识边界对照。
