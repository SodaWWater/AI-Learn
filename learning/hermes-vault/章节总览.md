# Hermes 章节总览

下面的编号和标题严格采用《Hermes Agent：源码驱动的完整学习大纲与 Codex 交接说明》。当前已产出第 4–6 章正文；第 1–3 章有正式文件位置但保留占位，后续章节先记录边界，避免把未写内容误认为已完成。

| 章节 | 主题 | 状态 | 主要边界 |
|---|---|---|---|
| 1 | 系统全貌、对象关系与运行边界 | 正式占位 | 入口、Gateway、Session、AIAgent、Turn 边界 |
| 2 | Turn 生命周期、租约与并发隔离 | 正式占位 | 接纳、Lease、queue/steer/interrupt、finally |
| 3 | Agent Loop 与 Iteration | 正式占位 | LoopState、phase、retry、tool round、finalizer |
| 4 | Context Engineering 与请求组装 | 初稿已建立 | Context 对象、文件装载、system/messages/tools、Provider 请求 |
| 5 | 压缩、Session 轮换与恢复 | 初稿已核（见讲解稿） | 压力检测、工具回收、摘要、in-place、rotation、回滚；勿与 `micro_compaction.py` 混名 |
| 6 | Memory 系统：架构、生命周期、存储、召回与可靠性 | 深度重构稿已建立 | Memory/Context/History 边界、Core vs Retrieval、USER/MEMORY/Skill scope、完整生命周期、Built-in 写读路径、Provider prefetch/sync、Consolidation、可靠性与面试映射 |
| 7 | Tool Registry、验证、执行与结果轨迹 | 待编写 | 注册、Schema、调用、验证、执行、结果回流 |
| 8 | Environment、Sandbox 与执行安全 | 待编写 | 执行后端、路径/网络/凭据/超时/清理 |
| 9 | Provider、流式 API 与可靠性 | 待编写 | 适配、stream、usage/cost、重试、fallback |
| 10 | Subagent、Delegate、Todo 与规划概念 | 待编写 | 子 Agent、父子 Session、Todo 与概念映射 |
| 11 | Gateway、多渠道、忙碌输入、Cron 与投递 | 待编写 | 路由、渠道、busy policy、Cron、投递 |
| 12 | Observability、Eval、测试与端到端综合 | 待编写 | 日志、Trace、Eval、不变量、综合案例 |

“正式占位”不代表旧资料正文已经被采纳；“初稿已建立”或“深度重构稿已建立”也不代表通过最终严格验收。每章完成前都必须绑定源码提交、来源定位、案例、异常恢复和验证命令。
