## 第 4–5 章统一口径

- “对话轨迹”是教学名称，指 `conversation_history` 与 `messages` 的关系，不是 `TurnContext` 字段。
- “活动行”指 SessionDB 中 `active=1` 的消息；`active=0, compacted=1` 的旧行已归档，不进入下一次活动历史。
- `in_place` 缺省按 True 处理；轮换是 `in_place: false` 的旧提交路径，不等于用户执行 `/new`。
- Skills 分三层：system 中的 Skills 索引、Provider `tools` 参数中的工具 Schema、`skill_view` 返回到 `messages` 的 `SKILL.md` 正文。
- `prune_tool_results_only` 是确定性工具结果减枝和自身数据库提交；`micro_compaction.py` 的 `_micro_compact` 是另一条默认关闭的滚动轮次摘要路径。

## 文件名约定

`SOUL.md` 是 Agent 身份文件；`USER.md` 是用户画像；`MEMORY.md` 是一般可复用记忆；项目上下文候选包括 `.hermes.md/HERMES.md`、`AGENTS.md`、`CLAUDE.md` 和 `.cursorrules`，具体选择必须以固定源码为准。
