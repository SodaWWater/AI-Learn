## 2. 第五章正文已修正的错误

以下问题已在 `chapters/05-context-compression-session-rotation-recovery.md` 中按 `f97a410` 改过：

1. **术语撞车：Micro-compaction。** 原文把 `prune_tool_results_only` 叫做 Micro-compaction。官方 `agent/micro_compaction.py` 是默认关闭的滚动轮次摘要。现已拆开两行术语。
2. **序列化标签。** 原文写成 `[TOOL:read_file]`。实际是 `[TOOL RESULT {tool_call_id}]:`，assistant 的调用是 `[Tool calls:\n  name(args)\n]`。
3. **预检 Gate 含“并发锁”。** 锁在 `compress_context` 内获取；预检是压完后用 `compression_skipped_due_to_lock` 判断并退还 attempt。
4. **漏写 `should_defer_preflight_to_real_usage`。** 无锚点的 rough 超阈值要等一次真实 usage。
5. **漏写双层阈值。** Gateway hygiene 85%，Agent compressor 默认 50%。
6. **漏写 `protect_first_n` 会 decay。** 第一次压缩后 `_effective_protect_first_n` 返回 0。
7. **`_candidate_rejected` 是四段。** abort / 无进展 / 空 transcript / attempt 被取代。反增长在 `_salvage_or_refuse_grown_transcript`。
