## 怎样读懂本 Vault

每章都会把三个层次分开：

1. Hermes 的持久事实（SessionDB、Markdown 文件和状态行）；
2. 运行时对象（`TurnContext`、工作消息、压缩器状态）；
3. Provider 请求副本（system、messages、tools 和 API 参数）。

文件名、类名和函数名保持原样；中文只解释它们的含义，不把专有名词直译成另一个看似相同的概念。所有源码结论都绑定固定提交，换版本时必须重新核对。
