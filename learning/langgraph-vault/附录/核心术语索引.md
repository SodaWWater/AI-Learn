# 核心术语索引

这只是 Part 1 的位置索引，不是完整知识章节。

| 术语 | 当前阶段先怎样理解 | 所属区域 |
|---|---|---|
| 状态（State） | 当前 Graph 的共享应用状态快照 | Graph Definition |
| 节点（Node） | 执行具体工作逻辑的函数 | Graph Definition |
| 边（Edge） | 决定固定或条件化的后续执行路径 | Control Flow |
| Reducer（状态合并函数） | 决定字段收到 State Update 后怎样合并 | Graph Definition / Runtime |
| `Command` | 将状态更新、跳转、恢复等控制意图组合到一个控制对象中 | Control Flow |
| `Send` | 运行时动态创建并分发任务 | Control Flow |
| 运行时（Runtime） | 真正激活节点并推进 Graph 的执行层 | Runtime |
| 超级步（Super-step） | LangGraph 底层图执行的一轮离散推进 | Runtime |
| 运行时上下文（Runtime Context） | 运行需要但不适合放进 State 的依赖或配置 | Runtime |
| 线程（Thread） | 一条可持续的 Graph 执行 / 会话状态线 | Persistence |
| 检查点（Checkpoint） | 某条 Thread 的 Graph 状态快照 | Persistence |
| 检查点持久化器（Checkpointer） | 保存和读取 Thread Checkpoint 的持久化机制 | Persistence |
| 存储（Store） | Graph State 之外的跨 Thread 长期应用数据 | Persistence |
| 人在回路（Human-in-the-loop） | 执行过程中引入人工查看、修改或批准 | Human-in-the-loop |
| `interrupt()` | 暂停 Graph 并向外部暴露等待处理的信息 | Human-in-the-loop |
| 子图（Subgraph） | 组合进父 Graph 的另一个 Graph | Composition |
| 多智能体系统（Multi-Agent System） | 在基础 Graph / Subgraph / Routing 机制上组织多个 Agent | Composition |
| 图应用程序接口（Graph API） | 显式使用 State / Node / Edge 建模 | API Style |
| 函数式应用程序接口（Functional API） | 保留普通 Python 控制流，通过 entrypoint / task 获得 LangGraph Runtime 能力 | API Style |

详细机制会在后续章节展开。遇到术语时先回到其所属区域，不要独立死记定义。
