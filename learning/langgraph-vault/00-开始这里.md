# 从这里开始

你现在的第一目标不是记住几十个 LangGraph API，而是先回答四个问题：

1. **LangGraph 在 Agent 系统里到底负责什么？**
2. **LangGraph 自己由哪些核心机制组成？**
3. **一次 Graph 从输入到结束到底怎样运行？**
4. **作为开发者，我到底怎样把这些东西编排出来？**

只要这四个问题还不能连成一张图，就暂时不要进入大量生产题。
