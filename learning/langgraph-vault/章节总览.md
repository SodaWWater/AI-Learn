入口：[[讲解/04-深度面试主链/00-Part4导航]]。

```text

API → Application → Graph Runtime → Node → LLM / Tool → State → Response
```

## 贯穿业务

后续正式答题继续优先使用“集团采购经营数据分析 Agent”做具体例子：数据查询、清洗、异常识别、并行下钻、归因、报告、主动预警和人工确认。生产题会在同一业务上扩展权限、多租户、幂等、失败恢复、评估与可观测性。
