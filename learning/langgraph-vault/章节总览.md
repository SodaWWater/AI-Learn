## Part 2 的定位

Part 1 是静态地图，Part 2 是动态运行电影。Part 2 不再满足于“State 是共享状态”这类短定义，而是固定一份采购经营教学数据，逐步展示：

```text
用户请求
→ graph.invoke
→ 初始 State
→ Node 执行
→ State Update
→ Reducer 合并
→ Updated State
→ Routing
→ Parallel Nodes
→ 汇总
→ Report
→ END
```

同时从业务流程、LangGraph Runtime、调用时序、State 生命周期和 Checkpoint 生命周期五个角度观察同一条执行链路。

## 贯穿业务

全程使用同一个“集团采购经营数据分析 Agent”：从用户提出经营分析目标开始，获取采购数据、进行数据质量处理、指标计算、异常识别、下钻分析、业务解释、图表与报告生成，并在后续章节扩展到定时执行、主动预警、人工确认和多 Agent 协作。
