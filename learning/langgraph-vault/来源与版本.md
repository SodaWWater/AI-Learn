# 来源与版本

## 技术来源

Part 1 的 LangGraph 行为以官方文档为准，审核日期为 **2026-09-15**。

| 主题 | 官方来源 |
|---|---|
| 框架定位、LangChain / LangGraph / LangSmith 边界 | https://docs.langchain.com/oss/python/langgraph/overview |
| 图模型、状态、节点、边、Reducer、Command、Send、Runtime Context、Super-step | https://docs.langchain.com/oss/python/langgraph/graph-api |
| Checkpointer、Checkpoint、Thread、Store | https://docs.langchain.com/oss/python/langgraph/persistence |
| Human-in-the-loop、`interrupt()`、`Command(resume=...)` | https://docs.langchain.com/oss/python/langgraph/interrupts |
| Subgraph | https://docs.langchain.com/oss/python/langgraph/use-subgraphs |
| Functional API | https://docs.langchain.com/oss/python/langgraph/functional-api |

当前 Part 1 **没有固定到一个精确的 `langgraph` Python package 版本号**，而是绑定到上述官方文档在审核日的公开口径。后续开始可运行代码章节时，应增加环境锁定文件并记录实际安装版本。

## 业务案例来源边界

贯穿的“集团采购经营数据分析 Agent”是教学抽象，参考用户提供的企业数据 Agent、供应链分析和采购智能化材料中的常见业务形态：自然语言问数、跨源取数、异常下钻、报告生成、预警与决策辅助。

用户提供的原始演示材料不复制进公开仓库，也不把其中企业名称、业务数据或效果数字作为 LangGraph 技术结论。技术行为仍只由 LangGraph 官方资料支撑。
