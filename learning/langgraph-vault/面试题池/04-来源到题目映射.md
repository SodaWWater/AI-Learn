## 交叉来源最明显的主轴

从映射能看到几个不是“单一题库制造”的主题：

- **为什么 LangGraph / 怎么映射真实系统**：S01、S02、S05、S07；
- **State / Checkpoint / 并发**：S02、S04、S05、S06 + 多个专项题库；
- **长链路失败恢复**：S01、S02、S05、S07、S11、S15；
- **评测与监控**：S01、S02、S06、S07、S08；
- **Streaming 到前端**：S02 + S13 + S14；
- **安全与权限**：真实 Agent 面经中已有 guardrail / sensitive-data 追问，专项安全来源进一步补全 Tool 权限、多租户和沙箱；
- **Multi-Agent 的必要性与失败边界**：S01、S02、S03、S10，而不是只来源于多 Agent 教程。

这也是这些主题进入高价值题池的主要原因。
