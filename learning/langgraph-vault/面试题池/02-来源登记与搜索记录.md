## 3. 本轮搜索中发现但没有作为强证据的来源

有些网页会直接标注“Google/Amazon Asked”或“FAANG 高频”，但没有公开可追溯的候选人面经支撑。此类来源**不用于证明公司真题或频率**，最多用来发现一个需要核验的主题。

同理，SEO 型“Top 50 / Top 250”文章的题量非常大，但题量不等于市场真实频率；本题池只用它们补一手面经覆盖不到的生产边界。

## 4. 搜索限制

1. 公开搜索只能看到已被索引的内容，不能代表所有公司、所有地区和未公开面试。
2. 牛客部分页面是作者二次整理，可能混入作者答案或归纳，不保证逐字等于面试官原话。
3. 部分页面有付费/截断，只使用公开可见部分，不推测隐藏内容。
4. Reddit / LeetCode 是用户自述；它能证明“有人报告被问过”，不能证明公司统一题库。
5. LangGraph API 迭代快，题目来源的旧答案不能直接当 2026 当前答案。
6. 本轮优先服务 AI Agent / AI 应用开发岗位，因此没有把纯算法、纯训练、纯 Java 后端题一起塞进 LangGraph 题池。

## 5. 搜索停止条件

本轮不是以“互联网永久绝对无遗漏”为完成标准，而是达到以下阶段性条件：

- 已覆盖至少 5 个第一人称/verified 英文或中文面试经历；
- 已覆盖多个 2026 国内 Agent 岗面经整理；
- 已覆盖多个独立 LangGraph 专项题库；
- State、Persistence、HITL、Reliability、Streaming、Evaluation、Security、Multi-Agent、System Design 均有来源；
- 连续补充搜索后，新出现内容主要落入已有主题，而不是产生新的一级类别；
- 已用当前官方文档识别明显版本漂移。

因此当前状态标记为 `research_snapshot`，而不是“永久完整”。
