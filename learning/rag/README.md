# RAG 学习产物

当前已经生成可审计的[全景思维导图草案](draft-overview.md)，以及 13 张模块子图。草案直接由原子知识目录生成，因此可以机械校验“每个原子知识点是否恰好出现一次”。

草案用于确认知识框架和学习顺序，不等于正式学习答案。严格验收通过前，图中的节点仍可能增加、改名或调整关系，但不会静默删除来源中的独立信息。

正式产物将在 RAG 严格验收通过后生成：

1. RAG 总体学习路线
2. RAG 总思维导图
3. 各一级模块子导图
4. 原理与工程落地并重的标准学习正文
5. 每个知识点的概要和相似知识对比
6. 前置、依赖、替代、优化、评估等知识关系图
7. 有原始出处的公开面试场景题关联

不单独生成口诀、记忆压缩、自测题、30 秒/2 分钟背诵答案或模拟面试话术。学习者基于完整知识自行组织表达。
