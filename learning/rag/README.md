# RAG 学习产物

当前有两类产物：

- [审计草图](draft-overview.md)及 13 张原子清单子图：由目录自动生成，用来机械检查“节点是否出现”；
- [正式学习总览](overview.md)及模块关系图：用有方向、有语义的关系线表达知识依赖、实现、改进、替代、治理和评估关系。

草案用于确认知识框架和学习顺序，不等于正式学习答案。严格验收通过前，图中的节点仍可能增加、改名或调整关系，但不会静默删除来源中的独立信息。

正式产物已开始分批生成，严格验收通过前标记为第一版而不是终稿：

1. RAG 总体学习路线
2. RAG 总览关系图
3. 各一级模块关系图和必要的机制子图
4. 原理与工程落地并重的标准学习正文
5. 每个知识点的概要和相似知识对比
6. 前置、依赖、替代、优化、评估等知识关系图
7. 有原始出处的公开面试场景题关联

已完成模块与文件路径由 [`formal-status.json`](formal-status.json) 登记，校验脚本会检查每个已完成模块的正文和关系图是否覆盖该模块全部原子知识。

不单独生成口诀、记忆压缩、自测题、30 秒/2 分钟背诵答案或模拟面试话术。学习者基于完整知识自行组织表达。
