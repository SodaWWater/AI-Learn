# RAG 模块关系图

本目录存放正式关系图。每个一级模块至少包含：

1. 一张概念依赖或分类关系图；
2. 一张机制、数据流或决策图；
3. 一份原子知识覆盖表。

图中的节点保留 `RAG-XX-XXX` ID。边必须写明关系语义；只有空间分组、没有关系线的图不能作为正式关系图。
